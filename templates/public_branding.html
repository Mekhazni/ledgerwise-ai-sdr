{% if page == "About" %}

Ledgerwise AI SDR is a demonstration application for AI-assisted sales outreach. It helps reviewers research companies, draft outreach and replies, and arrange calls in a controlled test workflow.

Ledgerwise uses Gmail to send emails only after a reviewer approves the exact draft version. It reads replies from known Gmail conversations when a reviewer chooses Sync inbox. Outbound Gmail messages go only to the configured test inbox.

{% elif page == "Privacy Policy" %}

Gmail permissions and use

Ledgerwise requests Gmail send access (gmail.send) and read-only access (gmail.readonly) for the connected test sender. The send permission lets Ledgerwise send approved emails to the configured test inbox. The read-only permission can read mailbox contents. Ledgerwise uses it during manual sync to fetch known conversation threads and import matching replies for the test workflow.

Processing, storage, and review

Ledgerwise stores conversation records in Supabase, including message subjects and bodies, message and thread identifiers, and sender and recipient information. Authorized reviewers can view conversations and draft history. When AI assistance is used, Ledgerwise can send reply text, relevant conversation history, and company research to Google Gemini to prepare and check drafts. A reviewer must approve the exact outgoing version before Ledgerwise sends it.

Access and protection

The public pages introduce the demo. Viewing conversation records requires an authorized dashboard account. Ledgerwise uses Supabase Auth to sign reviewers in and checks access on the server. Google OAuth credentials stay on the server, and browser sessions on the HTTPS deployment use secure, HTTP-only cookies.

The connected mailbox is used for controlled tests. Ledgerwise sends only to the configured test inbox. When booking is enabled and a test meeting is confirmed, Ledgerwise shares the selected time and test attendee details with Cal.com to create the booking.
